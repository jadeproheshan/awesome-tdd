# Awesome TDD

用于 AI Coding 的中文 **`$tdd` Skill**。一个安装入口，内部支持七类工作及批量推进；用自然语言决定本轮做什么、做到哪里。适用于 Go、Python 等项目，不绑定框架或测试工具。

## 使用

```text
$tdd 先帮我理清这个预约系统的需求，不写代码。
$tdd 沿用刚才的规则，只定最小接口和实体。
$tdd 先把全部测试写好跑一下，我看完再实现。
$tdd 继续实现，沿用刚才的测试。
$tdd 重构这段代码，保持行为。
$tdd 验收当前版本，只告诉我结果。
$tdd 把已确认的几个行为直接做完，不用逐步等我。
```

也可以要求“选最小行为”“每个行为先看测试”“每步确认”或“只做 A、B”。不要求记忆步骤名称、填写固定参数或从头走一遍。普通后续消息也能沿用当前 TDD 上下文，无须每次重新调用入口。

## 内部能力与停点

| 工作 | 默认边界 |
| --- | --- |
| 澄清需求 | 形成明确规则与待决事项，不写代码 |
| 选择行为/场景 | 列可观察预期，不写代码 |
| 设计契约/骨架 | 最小接口与必要实体，不实现业务 |
| 写测试 | 真实运行、给出测试代码，停在审阅点 |
| 实现 | 复用已有契约和测试，完成相关回归 |
| 重构 | 保持公开契约与业务行为，不扩功能 |
| 验收 | 默认只读，不擅自修复 |
| 批量推进 | 默认自动完成选定范围；用户指定停点时遵循 |

已确认的需求、契约和测试直接复用；实体尚不存在时先补最小接口。测试已经通过不制造 Red，编译/环境错误与业务失败分别报告，不改断言或硬编码样例来过关。

## 安装

仓库中只有 `skills/tdd/SKILL.md` 一个 Skill，不需要另外安装步骤入口。

可让 Codex 的 skill-installer 执行：

```text
从 jadeproheshan/awesome-tdd 安装 skills/tdd 到全局目录。
```

也可将 `skills/tdd/` 复制到工具的 Skills 目录。Codex 通常使用 `~/.codex/skills/tdd/`，安装后下一轮可用。

从旧版迁移时，移除此前从本仓库安装的八个 `tdd-*` 目录，保留 `tdd/`；不要删除其他来源的技能或自行修改过的内容。旧版内容仍可在 Git 历史查看。
