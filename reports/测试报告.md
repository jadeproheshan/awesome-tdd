# 单入口 TDD Skill 测试报告

日期：2026-11-25。当前受测文件仅 `skills/tdd/SKILL.md`，版本指纹见 [SHA-256 清单](skill-sha256.json)。

本轮将八个独立入口合并为一个 `$tdd`，全部指导保存在一份 50 行的 `SKILL.md` 中。七类工作与批量推进属于内部能力，不再作为独立安装入口。README 的调用、安装和迁移说明已同步。

## 本轮方法

使用 3 个不继承主会话的独立子 Agent，分别执行购物车默认批量、积分账户测试审阅与续接、待办清单多轮自然语言路由。只提供新 Skill、用户任务及隔离工作目录，没有提供参考实现或预期测试结论；未读取旧版样例。

后续以自然语言模拟用户确认、继续实现及重构，检查前轮范围与停点能否跨轮保留。主 Agent 检查代码、日志与哈希，并在独立进程重新运行保存的项目样例。

业务样例使用 Python 3.9.6 标准库 `unittest`。Skill 格式校验使用官方 `quick_validate.py`，运行于 Python 3.12.14 / PyYAML 6.0.4。测试未要求用户记忆内部步骤名或填写参数。

## 语义路由与停点结果

| 用户自然语言请求 | 观察到的行为 | 结果 |
| --- | --- | --- |
| “帮我完成这些购物车功能”，未指定 batch | 自动按行为写测试、运行、实现并回归；只做指定范围，没有增加删除、支付或持久化；最终 7 项测试通过 | 符合 |
| “先理清需求，不写代码” | 只形成规则、待决事项和建议，没有写代码或测试 | 符合 |
| “先列场景，然后只定接口，落骨架，别实现” | 组合行为选择与契约设计，交付最小 `TodoList` 骨架；导入/调用检查与业务通过分别说明，没有进入实现 | 符合 |
| “全部测试写好跑一下，我看完再实现” | 积分账户整批 13 个测试方法已写并实际运行，产生 29 个断言失败、0 个运行错误；仍为空骨架，在实现前停止 | 符合 |
| 审阅后“继续实现，沿用这些测试” | 直接复用契约和测试，不重开需求讨论；原 13 项测试全部通过，测试 SHA-256 不变 | 符合 |
| “每步确认，下一步写测试” | 写出待办清单测试并实际运行，停在测试审阅；7 个方法产生 9 个骨架 `NotImplementedError`，如实区分为错误，没有冒称业务断言失败 | 符合 |
| 下一轮只说“继续实现” | 沿用前轮上下文实现，7 项测试通过且测试哈希不变；继续保留“每步确认”，未自动重构或另起验收 | 符合 |
| “只做一个重构，内部字段改名，接口行为不变” | 只进行内部字段改名，公开接口和测试不变，重构前后 7 项测试均通过 | 符合 |
| “补空白输入测试，只写测试给我看” | 新测试直接通过，共 2 项测试通过；生产代码哈希不变，没有制造 Red，停在测试审阅 | 符合 |
| “验收当前版本” | 真实观察到 `0 != 5` 的业务失败；实现和测试哈希不变，没有擅自修复 | 符合 |

本轮未观察到需要修改 Skill 的路由或停点偏差。格式校验通过；当前仓库的 `skills/` 下只保留 `tdd/`。

## 可复现样例回放

仓库根目录运行：

```sh
python3 -B tests/replay.py
```

本轮新样例的主 Agent 复跑结果：

```text
PASS unified-cart: (7, 0, 0), exit=0
PASS unified-points-review: (13, 29, 0), exit=1
PASS unified-points-complete: (13, 0, 0), exit=0
PASS unified-already-green: (2, 0, 0), exit=0
PASS unified-read-only: (1, 1, 0), exit=1
PASS unified-todo-review: (7, 0, 9), exit=1
PASS unified-todo-complete: (7, 0, 0), exit=0
```

括号依次是测试方法数、断言失败数、运行错误数。审阅阶段的未实现样例及只读验收错误样例故意保留失败；回放器检查这些预期失败，因此整体退出码应为 0。`subTest` 可在一个测试方法中产生多个失败或错误。

本轮 4 组已完成/已有通过样例共 29 个测试方法通过。另外保留并复跑了旧版 6 组项目样例，结果符合预期，作为历史回归，不算作新 Skill 的独立路由验证。回放脚本只运行保存的代码，不再次调用 AI，不能单独证明 Skill 的选择行为。

## 验证边界

本轮抽样覆盖单入口的主要意图、默认批量、整批测试审阅及跨轮确认节奏，不证明所有自然语言表达都能正确路由。“每个行为先看测试”等其他表达仍由 Skill 规定，本轮未单独覆盖。未执行 Go 编译、竞态检查、数据库、网络依赖、并发业务或复杂环境修复。静态格式校验、AI 行为实测与项目样例回放是三种不同证据，不能互相替代。
